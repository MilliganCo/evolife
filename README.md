# Evolife - Эволюционная симуляция "Игра Жизнь"

Эволюционная симуляция клеточного автомата "Игра Жизнь" с генетической системой, мутациями и наследованием правил поведения. Клетки могут эволюционировать, развивать новые стратегии выживания и передавать их потомкам.

## Особенности

- **Генетическая система**: Каждая клетка имеет геном с правилами рождения и выживания
- **Мутации и кроссовер**: Клетки наследуют и мутируют генетические признаки
- **Видовое разнообразие**: Автоматическая кластеризация и анализ видов
- **ASCII визуализация**: Красивая консольная графика в стиле Dwarf Fortress
- **Множественные режимы отображения**: Обычный, возраст, виды, плотность
- **Сохранение/загрузка**: Полное сохранение состояния симуляции
- **Метрики и анализ**: Детальная статистика эволюции

## Установка

```bash
# Клонирование репозитория
git clone https://github.com/evolife/evolife.git
cd evolife

# Установка зависимостей
pip install -r requirements.txt

# Установка в режиме разработки
pip install -e .
```

## Быстрый старт

```bash
# Классическая "Жизнь" без мутаций
python main.py --width 160 --height 80 --mutation-rate 0 --fps 30

# Эволюция от случайного шума
python main.py --seed 42 --init-density 0.2 --mutation-rate 0.02 --color --fps 20

# Старение как селективный фактор
python main.py --age-max-default 32 --mutation-rate 0.01

# Жесткие виды (без кластеризации)
python main.py --species-hamming-threshold 0 --mutation-rate 0.005
```

## Управление

| Клавиша | Действие |
|---------|----------|
| `Пробел` | Пауза/продолжить |
| `.` | Один шаг |
| `+/-` | Ускорить/замедлить |
| `r` | Случайная область |
| `m` | Включить/выключить мутации |
| `s` | Сохранить состояние |
| `l` | Загрузить состояние |
| `a` | Переключить режим отображения |
| `c` | Переключить цвета |
| `i` | Показать информацию |
| `h` | Показать справку |
| `q` | Выход |

## Режимы отображения

- **Обычный**: Отображение клеток с их глифами и цветами
- **Возраст**: Интенсивность цвета зависит от возраста клетки
- **Виды**: Цвет зависит от генетического вида
- **Плотность**: Отображение локальной плотности клеток

## Параметры командной строки

### Основные параметры
- `--width WIDTH` - Ширина поля (по умолчанию: 120)
- `--height HEIGHT` - Высота поля (по умолчанию: 60)
- `--seed SEED` - Семя для генератора случайных чисел
- `--fps FPS` - Частота кадров (по умолчанию: 30)

### Генетика и правила
- `--default-rule RULE` - Правило по умолчанию (по умолчанию: B3/S23)
- `--mutation-rate RATE` - Глобальный множитель частоты мутаций (по умолчанию: 1.0)
- `--max-mutations-per-birth N` - Максимум мутаций за рождение (по умолчанию: 2)
- `--species-hamming-threshold N` - Порог Хэмминга для видов (по умолчанию: 2)
- `--age-max-default N` - Максимальный возраст по умолчанию (по умолчанию: 64)
- `--catastrophe PROB` - Вероятность катастрофы на клетку (по умолчанию: 0.0)

### Инициализация
- `--init-density DENSITY` - Плотность начального заполнения (по умолчанию: 0.15)

### Отображение
- `--color` - Включить цветной режим
- `--empty-dot` - Показывать точки вместо пробелов для пустых клеток

### Файлы
- `--record FILE` - Файл для записи метрик (JSONL)
- `--load FILE` - Файл состояния для загрузки
- `--save-interval N` - Интервал автосохранения в тиках (по умолчанию: 500)

## Генетическая система

### Геном клетки

Каждая живая клетка содержит:

- **birth_mask** (9 бит): Условия рождения (число соседей 0-8)
- **survive_mask** (9 бит): Условия выживания (число соседей 0-8)
- **mut_bits** (8 бит): Частота мутаций (0-255, квантованная)
- **glyph_id** (0-K-1): Индекс ASCII символа
- **color_id** (0-15): Индекс ANSI цвета
- **age_max** (1-255): Максимальный возраст

### Наследование

При рождении новой клетки:

1. **Выбор родителей**: Турнирный отбор среди живых соседей
2. **Кроссовер**: 
   - Маски: однородный кроссовер 50/50
   - Скалярные гены: случайный выбор родителя
3. **Мутации**: Применяются с вероятностью `mutation_rate`
4. **Ограничения**: Максимум `max_mutations_per_birth` мутаций

### Виды

Виды определяются парой масок `(birth_mask, survive_mask)` и кластеризуются по расстоянию Хэмминга с порогом `species_hamming_threshold`.

## Форматы файлов

### Состояние (.bin)
Бинарный формат с версионированием и сжатием:
- Заголовок с магическим числом и версией
- Размеры поля и тик
- Состояние генератора случайных чисел
- Матрица клеток
- Геномы, возрасты и максимальные возрасты

### Метрики (.jsonl)
JSON Lines формат с метриками на каждый тик:
```json
{"t": 100, "alive": 150, "species": 5, "top": [[[8, 16], 50]], "entropy": 2.3}
```

### Конфигурация (.toml/.yml)
```toml
[evolife]
width = 120
height = 60
fps = 30
color_enabled = true
mutation_rate_multiplier = 1.0
```

### Классическая эволюция
```bash
python main.py --width 200 --height 100 --init-density 0.1 --mutation-rate 0.01 --color
```

### Быстрая эволюция
```bash
python main.py --width 100 --height 50 --mutation-rate 0.05 --max-mutations-per-birth 5
```

### Стабильные виды
```bash
python main.py --species-hamming-threshold 0 --mutation-rate 0.001
```

### Катастрофы
```bash
python main.py --catastrophe 0.001 --mutation-rate 0.02
```
